# Patients-Demographic-Analysis
Analyzed 25,000 Health_visits_data (4,965 patients, 10 services, 36 months, Jan 2024–Aug 2026) and 44,428 total visits via Power BI. Ages 45+ drive 34.5% of demand, and Northwest records 9.06 repeat visits/patient. The 3-page dashboard guides regional and demographic healthcare planning. Ultimately, the project turns raw operational data into clear, practical priorities like strengthening chronic care pathways, keeping pediatric emergency care ready, and addressing high repeat-use in specific regions.
